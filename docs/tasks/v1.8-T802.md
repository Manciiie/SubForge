# [v1.8-T802] — Relecture ciblée

**Version** : 1.8.0 · **Statut** : `[x]` · **Dépend de** : v1.6 / v1.7 (parallélisme)

## Objectif
Option pour ne relire que les scènes où une erreur est plausible, et gagner du temps de relecture.

## Périmètre
**Inclus** : Case « ciblée (plus rapide) » sous « Relecture IA » (décochée par défaut) ; scène relue si elle contient pronoms/accords (he, she, you, I'm, guy, girl…), un personnage du contexte, une expression toute faite ou une phrase coupée sur deux sous-titres ; formules figées sans risque ignorées (« Thank you », « See you ») ; analyse pour l'anglais seulement (langue détectée sur 400 répliques si « automatique ») ; bilan « N relues, M sans risque sautées », progression sur les seules scènes relues.

## Cas limites (avant de coder)
- Langue d'origine autre que l'anglais → tout est relu. Pas de contexte du film → seuls pronoms, expressions et phrases coupées comptent. Option décochée → tout est relu comme avant.

## Critères d'acceptation
- [x] Seules les scènes à risque partent en relecture ; bilan et progression justes
