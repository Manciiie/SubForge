# [v1.10-T1001] — Conseiller de modèle d'IA locale

**Version** : 1.10.0 · **Statut** : `[x]` · **Dépend de** : v1.6-T602 (mesure sur le PC)

## Objectif
Choisir le modèle le plus rapide pour la carte graphique, à qualité de traduction équivalente, et ne
plus perdre de temps avec les modèles qui « réfléchissent » avant de répondre.

## Périmètre
**Inclus** : carte détectée (nvidia-smi, sinon nom donné par Electron + table des cartes courantes,
sinon mémoire vidéo choisie à la main et mémorisée) ; modèles installés lus chez Ollama (taille,
paramètres, quantification, famille, capacité « réflexion » via /api/show) ; verdict par modèle
(bon choix / trop gros pour la carte / version plus rapide disponible / modèle qui réfléchit) ;
recommandation pour la carte avec la commande `ollama pull` exacte (copiable) ; modèles qui
réfléchissent : réflexion coupée pour la traduction et la relecture (`think: false`).
**Exclu** : télécharger le modèle depuis SubForge (Ollama le fait, commande fournie).

## Cas limites (avant de coder)
- Pas de carte NVIDIA / nvidia-smi absent → nom seul, mémoire vidéo demandée.
- Carte inconnue de la table → mémoire vidéo demandée.
- Ollama arrêté → conseil sur la carte seule, message clair.
- Aucun modèle installé → recommandation seule.
- Ollama ancien sans `capabilities` dans /api/show → famille connue (qwen3, deepseek-r1…) sinon pas de `think`.
- Modèle « fp16 » / « q8_0 » → conseiller la version q4_K_M (tag par défaut).
- Sortie de nvidia-smi inattendue → ignorée, repli sur Electron.

## Critères d'acceptation
- [x] RTX 4060 Laptop 8 Go + qwen2.5:7b-instruct-q8_0 → `ollama pull qwen2.5:7b` proposé (voir Écarts)
- [x] Modèle de 13 Go sur 8 Go → « trop gros pour la carte »
- [x] Modèle qui réfléchit → `think: false` envoyé en traduction et relecture
- [x] Carte non détectée → choix de la mémoire vidéo, mémorisé

  votre carte graphique » dans Moteurs (`js/conseils.js`).
- **Vérifié** : `tests/conseils-ia.test.js` (nvidia-smi, table, mémoire à la main, verdicts sur 4/8/12/24 Go,
  think:false par capacité ou par famille, une seule demande /api/show par modèle) ; e2e `v110.js`
  (carte non détectée → 8 Go choisis, verdicts, conseil, copie, think:false en traduction et relecture).
