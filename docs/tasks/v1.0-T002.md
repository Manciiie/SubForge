# [v1.0-T002] — Module : pistes de sous-titres des vidéos

**Version** : 1.0.0 · **Statut** : `[x]` · **Dépend de** : T001

## Objectif
Glisser un film et traduire directement une de ses pistes de sous-titres texte.

## Périmètre
**Inclus** : `ffprobe` liste les pistes (langue, titre, codec, forcés/par défaut) ; pistes image
(PGS, VobSub, DVB) affichées « non traduisibles » ; `ffmpeg` extrait la piste choisie en SRT
(subrip/mov_text/webvtt) ou ASS (ass/ssa) dans un dossier temporaire ; annulation = processus tué,
dossier temporaire supprimé ; délais max.
**Exclu** : remuxer la piste traduite dans la vidéo (proposé pour la suite).

## Implémentation
- **Service** : `src/main/services/video.js`
- **Binaires** : `vendor/win/ffmpeg.exe`, `ffprobe.exe` → `resources/bin/` (D-004)
- **Protections** : `spawn` sans shell + `argumentsCommande`, chemin absolu du binaire, timeout,
  kill à l'annulation et à la fermeture, sortie de ffprobe validée (JSON, taille bornée).

## Critères d'acceptation
- [x] MKV avec piste SRT + piste ASS → les deux listées avec leur langue
- [x] Extraction puis traduction → `Film.fr.srt` à côté du film, vidéo intacte
- [x] Fichier nommé avec `"&|;` → aucune commande injectée
- [x] Piste PGS → non sélectionnable, message clair
