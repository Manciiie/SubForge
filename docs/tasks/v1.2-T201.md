# [v1.2-T201] — Ajouter la piste traduite au film

**Version** : 1.2.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Obtenir un seul fichier vidéo qui contient la piste de sous-titres traduite, prête à choisir dans le lecteur.

## Périmètre
**Inclus** : case « Ajouter la piste traduite au film » dans les options de Traduire (mémorisée) ;
après la traduction d'une vidéo, `ffmpeg -c copy` crée `Film.FR.mkv` à côté : toutes les pistes
d'origine (vidéo, audio, sous-titres, polices jointes) + la piste traduite, langue et nom posés
(« Français »), cochée par défaut (les autres décochées) ; MP4/AVI/… → copie en MKV ; écriture
dans un `.part` puis renommage ; original jamais modifié ; progression en %, Annuler ; place libre
vérifiée avant ; bilan sur la carte + « Ouvrir le dossier » sur la copie.
**Exclu** : remplacer le fichier d'origine ; incruster les sous-titres dans l'image.

## Cas limites (avant de coder)
- Sous-titre seul déposé (pas de vidéo) → option sans effet, rien à intégrer.
- Disque presque plein → refus avant de commencer, message avec la place nécessaire.
- Annuler pendant la copie → `.part` supprimé, sous-titre traduit gardé.
- Film.FR.mkv existe déjà → `Film.FR (2).mkv`.
- Piste de données non copiable en MKV (MP4 avec piste « timecode ») → ignorée.
- Échec de ffmpeg → traduction gardée, carte en alerte « intégration impossible : … ».

## Critères d'acceptation
- [x] MKV (2 pistes de sous-titres) + traduction → Film.FR.mkv avec 3 pistes, la française nommée, par défaut, vidéo identique (même taille de flux)
- [x] MP4 → Film.FR.mkv lisible
- [x] Annuler → aucun .part restant
