# [v1.1-T104] — Saison entière

**Version** : 1.1.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Glisser (ou choisir) le dossier d'une saison et tout traduire en un clic.

## Périmètre
**Inclus** : dossiers acceptés par `traduction:analyser` ; parcours des sous-dossiers (profondeur 6,
1 000 fichiers max) ; tri naturel (E2 avant E10) ; vidéo ignorée si un sous-titre texte est à côté
(on traduit celui-là) ; « déjà traduit » ignoré (sous-titre dans la langue cible déjà présent) ;
bilan « 10 épisodes ajoutés, 3 ignorés (déjà traduits) » ; bouton « Choisir un dossier » ;
piste choisie automatiquement dans chaque épisode (langue source, pas « forcés »).
**Exclu** : suivre les raccourcis / liens symboliques.

## Cas limites (avant de coder)
- Dossier vide ou sans vidéo → « Aucun film ni sous-titre dans ce dossier ».
- Dossier système, corbeille, dossiers cachés → ignorés ; sous-dossier interdit en lecture → ignoré et compté.
- Lien symbolique / jonction → non suivi (pas de boucle).
- Plus de 1 000 fichiers → arrêt à 1 000, bilan le dit.
- Même fichier glissé deux fois (dossier + fichier) → une seule carte.
- 300 cartes → interface fluide.

## Critères d'acceptation
- [x] Dossier « Saison 1 » (3 MKV, dont un avec `.fr.srt` déjà présent, un sous-dossier) → 2 traduits, 1 ignoré

## Compte rendu
- **Fait** : `dossiers.js` (parcours, sélection par épisode), canal `traduction:explorer`, analyse par paquets de 4, bouton « Choisir un dossier », dossier affiché sur la carte, bilan en notification.
- **Vérifié** : `tests/dossiers.test.js` (tri naturel, déjà traduits, limite, lien symbolique en boucle) ; e2e `saison.js` (4 MKV réels, 3 traduits, 1 ignoré, deuxième passage).
- **Écarts** : dossier illisible testé seulement hors administrateur (ignoré ici : session en root).
