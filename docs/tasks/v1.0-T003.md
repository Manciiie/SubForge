# [v1.0-T003] — Module : moteurs de traduction

**Version** : 1.0.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Choisir DeepL ou l'IA locale, régler chacun et vérifier qu'il répond, depuis l'écran « Moteurs ».

## Périmètre
**Inclus** : DeepL : clé au coffre (gratuite `:fx` → api-free, sinon api), lots de 50 répliques,
contexte, formalité, `tag_handling=xml`, quota affiché, erreurs 403/456/429 (réessai) traduites.
Ollama : adresse (local/réseau privé en HTTP, sinon HTTPS), liste des modèles installés,
traduction par lots JSON numérotés avec contexte des répliques précédentes, réessai en lots plus
petits puis réplique par réplique si la réponse est incomplète.
**Exclu** : autres services (proposés pour la suite).

## Implémentation
- **Service** : `src/main/services/moteurs.js` (+ `langues.js`)
- **Canaux** : `moteurs:etat`, `moteurs:enregistrerCleDeepl`, `moteurs:supprimerCleDeepl`,
  `moteurs:testerDeepl`, `moteurs:modelesOllama`, `moteurs:testerOllama`
- **Protections** : clé jamais renvoyée à l'interface ni écrite au journal, `net.fetch` avec
  délai, réponses validées et bornées, URL de test injectable seulement hors version empaquetée.

## Critères d'acceptation
- [x] Clé enregistrée → l'interface n'affiche que `••••` ; `parametres.json` et journaux sans la clé
- [x] Clé fausse → « Clé DeepL refusée » ; Ollama éteint → « L'IA locale ne répond pas »
- [x] Réponse Ollama incomplète ou non JSON → réessai, jamais de réplique vide dans la sortie
