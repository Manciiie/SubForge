# [v1.7-T703] — Mémoire de traduction préchargée

**Version** : 1.7.0 · **Statut** : `[x]` · **Dépend de** : v1.6 (demandes simultanées)

## Objectif
Le premier fichier traduit ne paie plus la lecture de la mémoire de traduction, et l'application ne se fige pas pendant cette lecture.

## Périmètre
**Inclus** : Lecture asynchrone 1,5 s après l'ouverture, analyse par tranches de 5 000 lignes avec une pause entre chaque ; une traduction pressée lit tout de suite (le préchargement s'efface) ; l'écran Moteurs affiche « lecture en cours » sans forcer la lecture.

## Cas limites (avant de coder)
- Fichier absent → rien. Fichier abîmé → lignes ignorées et comptées. Traduction lancée pendant le préchargement → lecture immédiate, résultat identique.

## Critères d'acceptation
- [x] Application jamais figée plus de 100 ms (mesuré : 27 ms pour 200 000 répliques, contre 390 ms d'un bloc avant) ; premier fichier : 0 ms de lecture

---
## Compte rendu
- **Fait** : `memoire.precharger()` (lecture par position, sans découper tout le texte), `etat()` sans lecture forcée, appel à l'ouverture dans `traduction.js`, affichage « lecture en cours » dans Moteurs.
- **Vérifié** : `tests/ia-locale-memoire.test.js` (réactivité mesurée, traduction pressée, ligne abîmée).
- **Écarts** : aucun.
