# [v1.4-T403] — Synchronisation automatique

**Version** : 1.4.0 · **Statut** : `[x]` · **Dépend de** : v1.0-T002 (ffmpeg), v1.1-T106 (en ligne)

## Objectif
Un sous-titre décalé (téléchargé, trouvé ailleurs, autre version du film) est recalé tout seul
sur le son du film avant d'être traduit.

## Périmètre
**Inclus** : case « Synchroniser sur le film » dans Traduire (mémorisée, activée par défaut).
Pour un sous-titre externe (SRT/ASS/VTT) dont la vidéo est à côté (même nom, avec ou sans code de
langue), ou téléchargé depuis la carte d'une vidéo : son du film extrait par ffmpeg (mono 8 kHz,
filtre voix 200–3 000 Hz), détection de parole par énergie (trames de 10 ms), corrélation par FFT
avec les moments où un sous-titre est affiché ; décalage cherché sur ±5 min, vitesses 1, 23,976↔24,
23,976↔25, 24↔25. Appliqué seulement si la correspondance est nette (pic net, score minimal) et
le décalage > 0,15 s ou la vitesse ≠ 1. Le fichier d'origine n'est jamais modifié : la traduction
porte les minutages corrigés. Bilan : « Recalé de +2,4 s » / « déjà synchronisé » / « incertain ».
La vidéo associée reçoit aussi la piste traduite (réglage « Résultat (vidéos) »).
**Exclu** : décalages non linéaires (coupures publicitaires, scènes ajoutées) ; pistes intégrées
au film (déjà synchronisées).

## Cas limites (avant de coder)
- Pas de vidéo associée → rien à faire, rien affiché.
- Vidéo sans piste audio → « pas de son : synchronisation impossible », traduction continue.
- Moins de 20 répliques → pas assez d'indices, synchronisation sautée.
- Pic ambigu (film très musical) → minutages laissés tels quels, « incertain ».
- Décalage poussant des répliques avant 0 → ramenées à 0, les vides supprimées.
- Annuler pendant l'analyse du son → ffmpeg tué.
- Plusieurs vidéos candidates → la même base exacte en priorité, sinon aucune.

## Critères d'acceptation
- [x] Film de test avec voix aux instants des sous-titres décalés de 3,2 s → recalé à ±0,1 s
- [x] Sous-titre à 25 i/s sur un film à 23,976 → vitesse détectée
- [x] Sous-titre sans rapport avec le son → « incertain », minutages inchangés
- [x] Film.en.srt + Film.mkv → Film.FR.mkv avec la piste recalée

## Compte rendu
- **Fait** : `synchro.js` (son → énergie 20 ms, parole = au-dessus de la médiane, corrélation FFT ±5 min, 7 vitesses, netteté ≥ 7 σ), `formats.lireMinutages/appliquerMinutages` (SRT, VTT, ASS), `dossiers.videoAssociee`, étape « Synchronisation… » ; la vidéo associée reçoit aussi la piste.
- **Vérifié** : `tests/synchro.test.js` (+3,2 s, −41,7 s, 25→23,976, sans rapport → incertain, vrai son décodé par ffmpeg, vidéo muette) ; e2e `v14.js` (Film.en.srt décalé de 2,5 s → Film.FR.mkv recalé à 0 ms près).
- **Écarts** : testé sur des sons fabriqués, pas sur un vrai film (bruitages, musique) : le seuil de netteté protège d'un mauvais recalage, au prix de « incertain » plus souvent.
