# [v1.1-T101] — ffmpeg 7.1

**Version** : 1.1.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Lire les vidéos aux formats inhabituels et les sous-titres Blu-ray avec un ffmpeg récent.

## Périmètre
**Inclus** : `scripts/preparer-ffmpeg.js` télécharge la wheel PyPI `imageio-ffmpeg 0.6.0` (ffmpeg 7.1
Windows, 7.0.2 Linux pour le développement), vérifie son SHA-256 figé, extrait le binaire (lecteur
zip sans dépendance) ; analyse de la sortie de `ffmpeg -i` compatible 7.x.
**Exclu** : ffprobe.

## Cas limites (avant de coder)
- Fichier téléchargé modifié ou tronqué → empreinte refusée, build arrêté.
- Sortie ffmpeg 7 (`subrip (srt)`, `[0x1200]`, `(hearing impaired)`) → pistes reconnues.
- Antivirus qui supprime `ffmpeg.exe` → « ffmpeg est introuvable… réinstallez » (déjà en 1.0).

## Critères d'acceptation
- [x] `ffmpeg -version` = 7.x dans `vendor/` ; empreinte fausse refusée
- [x] Tests vidéo (MKV réel, nom piégé, annulation) verts avec ffmpeg 7
- [x] `ffmpeg.exe` 7.1 vérifié sous Windows (wine ou PC réel)
