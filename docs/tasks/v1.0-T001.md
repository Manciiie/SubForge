# [v1.0-T001] — Module : formats de sous-titres

**Version** : 1.0.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Lire et réécrire SRT, ASS/SSA et WebVTT sans rien perdre d'autre que le texte traduit.

## Périmètre
**Inclus** : détection d'encodage (BOM UTF-8/UTF-16, UTF-8 strict, sinon Windows-1252) ;
SRT (balises `<i>`, `<b>`, `<font>`) ; ASS/SSA (en-têtes, styles, champs Dialogue, blocs `{\…}`,
`\N`) ; VTT (en-tête, réglages de position, NOTE/STYLE gardés) ; balises internes protégées par
marqueurs `<x n="…"/>` ; découpage/recomposition des lignes (répliques « - » gardées ligne à
ligne) ; nommage de sortie `Film.fr.srt` sans écraser ; écriture atomique ; refus > 20 Mo.
**Exclu** : formats image, SUB/MicroDVD, conversion de minutage.

- **Service** : `src/main/services/formats.js` (pur, testable sans Electron)
- **Long ?** non (quelques ms)
