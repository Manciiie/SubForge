# [v1.3-T301] — Expressions traduites par leur sens

**Version** : 1.3.0 · **Statut** : `[x]` · **Dépend de** : v1.1-T103 (glossaire), v1.0-T003 (moteurs)

## Objectif
Les expressions idiomatiques, l'argot et les tournures toutes faites (« break a leg », « it's raining
cats and dogs », « spill the beans ») sont traduites par leur sens, avec une tournure naturelle de la
langue d'arrivée, jamais mot à mot.

## Périmètre
**Inclus** :
- Consigne générale de l'IA locale : expressions, argot, dictons et jeux de mots traduits par leur
  équivalent naturel, même sens et même ton.
- Liste intégrée d'expressions anglaises courantes (langue d'origine anglais ou détection auto) :
  sens en clair + équivalent français ; pour les autres langues d'arrivée, le moteur part du sens.
  Formes conjuguées reconnues (spill / spills / spilled / spilling the beans).
- Expressions personnelles : expression, sens (facultatif), équivalent imposé (facultatif),
  langue d'origine et langue d'arrivée (ou « toutes »). Joker `*` = 1 à 3 mots quelconques.
- Pour chaque réplique, les expressions trouvées sont envoyées au moteur avec leur sens et leur
  équivalent : dans la demande (IA locale), dans le contexte (DeepL, non facturé).
- Écran « Expressions » : liste intégrée activable/désactivable (en entier et une par une),
  ajout / modification / suppression des expressions perso, recherche, « Tester une phrase ».
- Bilan sur la carte : « N expressions adaptées : … ».
- Mémoire de traduction : une réplique contenant une expression n'est pas reprise d'une traduction
  faite sans l'aide (clé de mémoire = texte + expressions repérées).

**Exclu** : listes intégrées pour d'autres langues d'origine que l'anglais ; DeepL « glossaires » et
« custom instructions » de l'API (comptes payants, forme exacte imposée, grammaire cassée).

## Cas limites (avant de coder)
- Expression qui contient un terme du glossaire (marqueur `<g/>`) → cherchée sur le texte sans
  marqueurs ; l'aide envoyée cite l'expression telle qu'écrite.
- Même expression perso et intégrée → la perso l'emporte.
- Expression vide, > 120 caractères, caractères `< > { }` → refusée avec message.
- Joker seul (« * ») ou expression d'un seul caractère → refusée.
- Doublon (même expression, mêmes langues) → refusé.
- Fichier expressions.json abîmé → mis de côté, liste vide, message ; liste intégrée toujours là.
- Plus de 2 000 expressions perso → refus.
- Plusieurs expressions dans une réplique → toutes envoyées (5 au plus par réplique).
- Langue d'origine non anglaise (choisie) → liste intégrée inactive, seules les perso de cette
  langue (ou « toutes ») servent.
- Moteur qui ignore l'aide → la traduction reste valable (simple aide), aucune erreur.

## Critères d'acceptation
- [x] « Break a leg! » envoyé à l'IA locale avec l'aide « means: good luck… French: Merde ! »
- [x] DeepL : l'aide part dans `context`, pas dans `text`
- [x] « He spilled the beans » reconnu (forme conjuguée)
- [x] Expression perso avec joker reconnue ; équivalent imposé transmis
- [x] Liste intégrée désactivée → aucune aide
- [x] Bilan de la carte : expressions adaptées listées
- [x] Mémoire : une réplique déjà traduite sans aide est retraduite avec l'aide
