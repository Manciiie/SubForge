# [v1.1-T105] — OCR des sous-titres Blu-ray (PGS)

**Version** : 1.1.0 · **Statut** : `[ ]` · **Dépend de** : T101

## Objectif
Traduire aussi les films dont les sous-titres sont des images (Blu-ray, PGS) : lecture du texte hors ligne, puis traduction.

## Périmètre
**Inclus** : piste PGS extraite telle quelle (`-c:s copy -f sup`) ou fichier `.sup` déposé ;
`services/pgs.js` décode les segments (PCS, PDS, ODS, END), les palettes YCbCr et le RLE ;
image de chaque réplique (texte noir sur blanc, contour retiré) ; OCR `tesseract.js` (WASM, hors
ligne) avec données de langue livrées (anglais, français, espagnol, allemand, italien, portugais,
néerlandais) ; plusieurs travailleurs en parallèle ; nettoyage des erreurs courantes (`|` → `I`) ;
le texte lu est enregistré à côté du film (`Film.en.srt`) puis traduit ; répliques peu sûres comptées.
**Exclu** : VobSub (DVD) et DVB (proposé pour la suite).

## Cas limites (avant de coder)
- `.sup` tronqué ou corrompu → répliques lisibles gardées, bilan « X images illisibles ».
- Langue de la piste sans données OCR → message « OCR non disponible pour <langue> ».
- Image vide (réplique effacée) → ignorée ; très grande image → refusée au-delà de 4096×4096.
- Annuler pendant l'OCR → travailleurs arrêtés, rien d'écrit.
- 2 000 images → progression visible, interface fluide (OCR hors de l'interface).

## Critères d'acceptation
- [ ] `.sup` fabriqué (texte rendu par ffmpeg) → texte relu ≥ 90 % de mots justes, minutages exacts
- [ ] MKV avec piste PGS → `Film.en.srt` (OCR) puis `Film.fr.srt` (traduit)
