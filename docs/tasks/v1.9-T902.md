# [v1.9-T902] — Ajouter la piste dans le film d'origine

**Version** : 1.9.0 · **Statut** : `[x]` · **Dépend de** : v1.7 (mémoire de travail), v1.2 (ajout au film)

## Objectif
Option pour ne pas garder deux exemplaires de chaque film : la version avec la piste remplace l'original, qui part à la corbeille.

## Périmètre
**Inclus** : Choix « Film d'origine avec la piste (l'original va à la corbeille) » dans « Résultat (vidéos) », avec confirmation ; nouvelle version écrite à côté (Film.subforge-en-cours.mkv), vérifiée (même durée à 1,5 s, une piste de plus), puis original à la corbeille de Windows et nouvelle version renommée (MP4/AVI → MKV du même nom) ; piste marquée SUBFORGE (étiquette invisible) ; un film déjà traduit par SubForge dans la langue choisie est signalé « Déjà traduit » et n'est retraduit que sur demande (« Retraduire quand même »), sans reprendre la piste ajoutée comme source.

## Cas limites (avant de coder)
- Vérification ratée → original gardé, nouvelle version supprimée, carte en erreur. Film.mkv déjà présent à côté de Film.mp4 → les deux gardés, Film.FR.mkv créé, la carte le dit. Corbeille impossible (fichier ouvert dans un lecteur, disque réseau) → original gardé, Film.FR.mkv. Annuler → fichier en cours supprimé. Place insuffisante → refus avant de commencer.

## Critères d'acceptation
- [x] MP4 → MKV avec la piste, original à la corbeille ; MKV remplacé sous le même nom ; conflit de nom → rien d'écrasé ; film déjà traduit → « Déjà traduit »
