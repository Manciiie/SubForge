# [v1.1-T107] — Recherche en ligne automatique pour toute une saison

**Version** : 1.1.0 · **Statut** : `[x]` · **Dépend de** : T104, T106

## Objectif
Un clic : SubForge cherche et télécharge les sous-titres de toutes les vidéos de la file qui n'en ont
pas, puis elles sont prêtes à traduire.

## Périmètre
**Inclus** : bouton « Chercher en ligne pour N vidéo(s) sans sous-titres » dans l'en-tête de la file ;
pour chaque vidéo, recherche (langue source, sinon anglais) puis **choix automatique sûr** :
correspondance exacte de l'empreinte, ou même saison + même épisode (séries), ou même titre (+ année)
pour un film ; jamais une traduction automatique ; sinon la vidéo reste « à choisir à la main » ;
téléchargement → la carte vidéo est remplacée par le sous-titre ; progression « 3 / 10 » ; bouton
Arrêter ; arrêt propre quand le quota du jour est atteint ; bilan final.
**Exclu** : choisir parmi plusieurs résultats incertains (reste manuel).

## Cas limites (avant de coder)
- Pas de clé → message et écran Moteurs, rien n'est lancé.
- Aucun résultat / résultat incertain → carte gardée, raison affichée (« aucun résultat sûr »).
- Quota du jour atteint au milieu → arrêt, bilan « 4 téléchargés, 6 restants (quota atteint) ».
- Hors ligne / erreur sur un épisode → les autres continuent, erreur affichée sur la carte.
- Arrêter → l'épisode en cours finit, les suivants ne sont pas cherchés.
- Double-clic sur le bouton → un seul lancement ; boutons désactivés pendant la recherche.
- Rythme : une recherche à la fois, petite pause entre deux (limite de l'API).

## Critères d'acceptation
- [x] Saison de 3 épisodes sans sous-titres (faux serveur) : 2 trouvés sûrs et téléchargés, 1 incertain laissé
- [x] Quota atteint → arrêt et bilan
- [x] Règle de choix testée (exact, épisode, film, traduction automatique refusée)

- **Vérifié** : tests (règle de choix, mode automatique, quota) ; e2e `enligne-saison.js` (3 épisodes : 2 trouvés, 1 laissé, traduction automatique jamais prise, puis traduits).
- **Écarts** : aucun.
