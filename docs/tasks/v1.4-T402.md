# [v1.4-T402] — Relecture par l'IA

**Version** : 1.4.0 · **Statut** : `[x]` · **Dépend de** : v1.0-T003 (IA locale)

## Objectif
Après la traduction, une seconde lecture par l'IA locale corrige ce qu'un traducteur humain
corrigerait : contresens, genre des personnages, noms qui changent, tu/vous incohérent, phrase
coupée sur deux sous-titres traduite en deux morceaux qui ne se suivent pas.

## Périmètre
**Inclus** : case « Relecture IA » dans Traduire (mémorisée, activée par défaut) ; marche avec
DeepL comme avec l'IA locale, dès qu'un modèle Ollama est choisi. Film découpé en scènes (silence
de plus de 6 s, 40 répliques au plus) ; pour chaque scène, le modèle reçoit original + traduction
et renvoie les corrections et les doutes. Une correction est refusée si elle perd un marqueur de
mise en forme, un terme du glossaire, si elle est vide, recopiée de l'original, ou 2,5 fois plus
longue. Bilan sur la carte (« Relecture : N corrigées, M à vérifier ») ; aperçu : répliques
corrigées marquées, avec la raison ; doutes marqués. Progression « Relecture… scène k/n », Annuler.
**Exclu** : relecture par DeepL (pas d'IA de relecture chez DeepL) ; modification à la main
(éditeur de répliques = autre proposition).

## Cas limites (avant de coder)
- Aucun modèle d'IA locale → pas de relecture, carte : « Relecture IA non faite : aucun modèle ».
- Ollama arrêté pendant la relecture → traduction gardée telle quelle, carte en alerte.
- Réponse illisible pour une scène → scène sautée (comptée), pas d'erreur.
- Réplique corrigée qui contenait un terme du glossaire absent de la correction → refusée.
- Numéro de ligne inconnu dans la réponse → ignoré.
- Annuler pendant la relecture → aucun fichier écrit.
- Très long film (3 000 répliques) → ~75 scènes, progression visible.

## Critères d'acceptation
- [x] Une correction valable est appliquée, une correction qui perd un marqueur est refusée
- [x] Bilan et aperçu montrent les corrections et les doutes
- [x] Ollama coupé pendant la relecture → fichier écrit avec la traduction, alerte sur la carte
- [x] Sans modèle → aucune requête de relecture, message clair
