# [v1.1-T106] — Sous-titres en ligne (OpenSubtitles)

**Version** : 1.1.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Quand un film n'a pas de sous-titres, les trouver en ligne en un clic puis les traduire.

## Périmètre
**Inclus** : `services/enligne.js` : API REST OpenSubtitles.com (`api.opensubtitles.com/api/v1`),
clé d'API (gratuite, créée par moi) et compte facultatif (mot de passe) au coffre ; recherche par
empreinte du fichier (hash OpenSubtitles) + titre / saison / épisode tirés du nom ; résultats triés
(correspondance exacte d'abord, puis téléchargements) ; téléchargement → `Film.en.srt` à côté du
film puis ajout à la file ; quota restant affiché ; carte de réglages dans Moteurs ; bouton
« Chercher en ligne » sur les cartes vidéo (mis en avant quand il n'y a aucune piste texte).
**Exclu** : autres sites (pas d'aspiration de pages).

## Cas limites (avant de coder)
- Pas de clé → bouton qui mène aux réglages, message clair.
- Hors ligne, délai dépassé, 401 (clé/compte refusé), 406/429 (quota du jour atteint) → messages français.
- Aucun résultat → « Rien trouvé pour ce film » (pas une liste vide muette).
- Lien de téléchargement vers un autre site que opensubtitles → refusé.
- Fichier reçu énorme, vide, compressé ou pas un sous-titre → refusé.
- Vidéo de moins de 128 Ko → recherche par nom seulement.
- Double-clic sur Télécharger → un seul téléchargement.

## Critères d'acceptation
- [x] Faux serveur au format officiel : recherche, téléchargement, fichier écrit, ajouté à la file
