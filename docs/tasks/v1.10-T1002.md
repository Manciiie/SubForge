# [v1.10-T1002] — Réglages d'Ollama pour la carte

**Version** : 1.10.0 · **Statut** : `[x]` · **Dépend de** : T1001

## Objectif
Activer les réglages d'Ollama qui réduisent la mémoire vidéo utilisée et permettent plus de demandes
à la fois : `OLLAMA_FLASH_ATTENTION=1`, `OLLAMA_KV_CACHE_TYPE=q8_0`, `OLLAMA_NUM_PARALLEL` = réglage
« Demandes simultanées » de SubForge.

## Périmètre
**Inclus** : lecture de l'état (Windows : variables utilisateur et système dans le registre via
`reg.exe` ; ailleurs : environnement) ; bouton « Activer pour moi » (Windows : `setx` pour
l'utilisateur, sans droits administrateur) et « Remettre comme avant » ; rappel de redémarrer Ollama ;
hors Windows : instructions à copier.
**Exclu** : redémarrer Ollama à la place de l'utilisateur ; variables système (droits administrateur).

## Cas limites (avant de coder)
- Variable définie au niveau système avec une autre valeur → affichée, non modifiée (l'utilisateur l'a voulue).
- `setx` échoue → message clair, rien de changé.
- Valeurs écrites uniquement depuis une liste fixe (jamais un texte venu de l'interface).
- Plateforme autre que Windows → instructions seulement, aucune commande lancée.

## Critères d'acceptation
- [x] État lu correctement (absent / actif / autre valeur) pour les trois réglages
- [x] « Activer pour moi » lance exactement 3 `setx` avec des valeurs fixes, sans shell
- [x] « Remettre comme avant » rétablit l'état d'origine (suppression des variables ajoutées)

---
## Compte rendu
- **Fait** : lecture `reg query` (utilisateur + système, l'utilisateur l'emporte), `setx` pour le compte
  (sans droits administrateur), anciennes valeurs gardées dans les paramètres pour « Remettre comme
  avant » (`reg delete` si la variable n'existait pas, sinon `setx` de l'ancienne valeur) ; instructions
  systemd hors Windows. `reg.exe` / `setx.exe` par chemin absolu (`%SystemRoot%\System32`), `execFile`
  sans shell, valeurs prises dans une liste fixe.
- **Vérifié** : tests avec un faux registre (3 `setx` exacts, aucun si déjà réglé, retour à l'état
  d'origine, refus clair si Windows refuse) ; e2e `v110.js` hors Windows (état, instructions, pas de bouton).
- **Écarts** : jamais lancé sur un vrai Windows (registre, `setx`) ; Ollama doit être redémarré à la main
  (dit à l'écran), SubForge ne le relance pas.
