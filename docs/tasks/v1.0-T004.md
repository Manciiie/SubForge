# [v1.0-T004] — Module : écran « Traduire »

**Version** : 1.0.0 · **Statut** : `[x]` · **Dépend de** : T001, T002, T003

## Objectif
Glisser un ou plusieurs films/sous-titres, choisir langues et moteur, traduire tout d'un clic.

## Périmètre
**Inclus** : zone de dépôt + bouton ; une carte par fichier (piste à choisir pour une vidéo,
statut, progression) ; langue source (auto) / cible (Français par défaut), moteur, format de
sortie (identique / toujours SRT), dossier de sortie (à côté du film par défaut) ; « Traduire
tout », « Annuler » ; aperçu original / traduit ; « Ouvrir le dossier ». Réglages mémorisés.
**Exclu** : édition manuelle des répliques (proposée pour la suite).

## Implémentation
- **Service** : `src/main/services/traduction.js` (file d'attente, progression par événement)
- **Canaux** : `traduction:analyser`, `traduction:lancer`, `traduction:annuler`,
  `traduction:apercu`, `traduction:ouvrirDossier`, `traduction:choisirDossierSortie` ;
  événement `traduction:progression`

## Critères d'acceptation
- [x] SRT + MKV glissés → deux fichiers traduits sur le disque, aperçu cohérent
- [x] Annuler pendant la traduction → arrêt, aucun fichier partiel
- [x] Erreur d'un fichier → les autres continuent, message clair sur la carte
- [x] Captures sombre/clair lisibles
