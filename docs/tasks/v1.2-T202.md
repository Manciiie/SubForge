# [v1.2-T202] — IA locale plus simple

**Version** : 1.2.0 · **Statut** : `[x]` · **Dépend de** : —

## Objectif
Que l'IA locale marche sans chercher : constat d'usage (moteur resté sur DeepL sans clé, modèle non choisi, « Error: » en anglais).

## Périmètre
**Inclus** : modèle choisi automatiquement s'il n'y en a qu'un (ou si le modèle choisi a disparu) ;
liste rafraîchie à chaque ouverture de Moteurs et au démarrage ; message « Ollama répond mais aucun
modèle n'est installé : tapez `ollama pull qwen2.5:7b`… » ; moteur basculé sur l'IA locale quand
DeepL n'a pas de clé et qu'un modèle est prêt (au démarrage, au choix d'un modèle, avant de lancer)
avec une notification ; « Error: » retiré de tous les messages.

## Cas limites (avant de coder)
- Ollama éteint au démarrage → pas de bascule, message habituel.
- Clé DeepL présente → jamais de bascule automatique.
- Plusieurs modèles → pas de choix automatique (sauf si le choisi a disparu : le premier).

## Critères d'acceptation
- [x] Sans clé DeepL, faux Ollama avec un modèle : au démarrage le moteur passe sur l'IA locale et le modèle est choisi
- [x] Message d'erreur sans « Error: »

---
## Compte rendu
- **Fait** : choix automatique du modèle, bascule automatique (démarrage, choix du modèle, avant de lancer), liste rafraîchie à l'ouverture de Moteurs, message « aucun modèle » avec la commande, « Error: » retiré partout.
- **Vérifié** : e2e `v12.js` (bascule et choix sans intervention, message sans « Error: »).
- **Écarts** : aucun.
